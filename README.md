# Pasta Mind Map

An interactive Vite + React pasta mind map that expands from a single root question into a 54-pasta decision tree.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Vercel

This repo is ready to import into Vercel as a Vite project.

- Framework preset: `Vite`
- Build command: `npm run build`
- Output directory: `dist`

The same settings are defined in `vercel.json`.
